06 · Agent & Safety

SQL 不是生成完就执行

Agent 先发现允许的 MCP 工具，解析股票实体，生成查询契约和 SQL；随后经过 Schema、业务语义、权限与只读 AST 多重校验。

实际执行 SQL · DuckDBvalidated
SELECT report_date, publish_date,
       operating_revenue_ttm, parent_net_profit_ttm,
       operating_cash_flow_ttm, invested_capital
FROM (
  SELECT ...
  FROM financial_period
  WHERE symbol = 'sh600519'
  QUALIFY ROW_NUMBER() OVER (
    PARTITION BY report_date
    ORDER BY publish_date DESC
  ) = 1
  ORDER BY report_date DESC LIMIT 12
) recent
ORDER BY report_date ASC;
01
工具边界

只能调用 Skill 允许且当前用户可见的 MCP 工具。

02
查询契约

粒度、来源表、过滤条件、指标和输出列必须完整。

03
Schema 校验

表受最小 Schema 图限制；字段必须存在于完整注册 Schema。

04
业务语义

最新交易日、最近报告期、披露版本和最终排序不可遗漏。

05
只读执行

单条 SELECT/WITH、显式字段、权限检查、最多返回 200 行。

↻
有限修正

失败 SQL 不得原样重试；简单确定性错误可在执行前安全修正。
