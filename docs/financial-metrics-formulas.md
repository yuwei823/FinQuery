# 财务派生指标公式表

> 本表定义候选指标的标准公式、依赖和异常值规则。指标名称、别名和概念解释统一登记在
> `backend/data/databases/trade_data/_terms.json`；其中状态为 `active` 的 P0 项同时保存可执行 SQL 公式和异常值规则，本表用于审阅和解释，其余指标仍是设计基线。

当前已上线字段：`pe_ttm`、`pb`、`pcf_ttm`、`earnings_yield_ttm`、`liabilities_to_assets`、`liabilities_to_equity`。它们随 `stock_daily` Parquet 生成，不需要跨表查询。

## 1. 数据可用性等级

| 等级 | 含义 |
|---|---|
| A | 当前 `stock_daily` 单表字段足够，可优先上线。 |
| B | 当前 `financial_statement` 核心字段足够，但需要期间标准化、TTM或披露日对齐。 |
| C | 原始财报包含依赖字段，但当前财报ETL尚未整理这些字段。 |
| D | 需要股本、分红、一致预期、资本成本等当前数据源未明确提供的数据。 |

## 2. 通用中间量

| 指标ID | 名称 | 标准公式 | 等级 | 关键规则 |
|---|---|---|---|---|
| `market_cap` | 总市值 | `stock_daily.total_market_cap` | A | 使用查询交易日收盘后的总市值。 |
| `avg_parent_equity` | 平均归母权益 | `(期初归母权益 + 期末归母权益) / 2` | B | 两端均须为当时已披露值；不可把多家公司权益相加后再平均单家公司比率。 |
| `avg_total_assets` | 平均总资产 | `(期初总资产 + 期末总资产) / 2` | B | 期初通常取十二个月前同口径期末。 |
| `revenue_ttm` | 营业收入TTM | 年报：本年累计；非年报：`上年年报 + 本年YTD - 上年同期YTD` | B | 必须先去重修订版本；缺任一组成项则为空。 |
| `parent_net_profit_ttm` | 归母净利润TTM | 同上TTM桥接公式 | B | 抽样已确认 `stock_daily.net_profit_ttm` 是合并净利润口径，不能替代归母净利润。 |
| `cfo_ttm` | 经营现金流TTM | 同上TTM桥接公式 | A/B | 当前 `stock_daily.cash_flow_ttm` 可直接用，但应确认源口径。 |
| `gross_profit_ttm` | 毛利润TTM | `营业收入TTM - 营业成本TTM` | C | 银行、保险、券商默认不适用。 |
| `ebit_ttm` | EBIT TTM | 标准化营业利润TTM，按会计口径调整明确的非经营项目 | C | 不在缺少明细时把营业利润无条件等同于EBIT。 |
| `ebitda_ttm` | EBITDA TTM | `EBIT TTM + 折旧TTM + 摊销TTM` | C | 不等于经营现金流。 |
| `nopat_ttm` | NOPAT TTM | `EBIT TTM × (1 - tax_rate)` | C | 税率需定义上下限及亏损期处理。 |
| `interest_bearing_debt` | 有息债务 | 短期借款 + 一年内到期有息债务 + 长期借款 + 应付债券 + 租赁负债等 | C | 不包含应付账款、合同负债等经营负债。 |
| `net_debt` | 净债务 | `有息债务 - 现金及现金等价物` | C | 若为负值表示净现金；不得用总负债替代。 |
| `enterprise_value` | 企业价值 | `总市值 + 有息债务 + 优先股 + 少数股东权益 - 现金及现金等价物` | C | 合并报表分母与少数股东权益必须匹配。 |
| `invested_capital` | 投入资本 | `股东权益 + 有息债务 - 现金及现金等价物` | C | 是否纳入少数股东权益、租赁负债须版本化。 |
| `noncash_working_capital` | 非现金营运资本 | `(流动资产 - 现金) - (流动负债 - 短期有息债务)` | C | 金融企业默认不使用。 |
| `capex` | 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | C | 不用投资活动现金流净额替代。 |

## 3. 估值指标

| 指标ID | 中文名/别名 | 标准公式 | 等级 | 无效或特殊处理 |
|---|---|---|---|---|
| `pe_ttm` | 滚动市盈率（合并口径）、PE TTM | P0：`总市值 / 合并净利润TTM` | A | 分母 `<= 0` 返回空值；不是严格归母口径。标准归母PE将在PIT财报层使用独立指标。 |
| `pe_static` | 静态市盈率、年报PE | `总市值 / 最近完整年度归母净利润` | B | 分母 `<= 0` 为NM；必须显示所用财年。 |
| `pe_forward` | 预测市盈率、Forward PE | `总市值 / 未来十二个月预测归母净利润` | D | 需记录预测来源和快照时间。 |
| `pb` | 市净率（总权益口径）、PB、PBV | P0：`总市值 / 所有者权益合计` | A | `stock_daily.net_assets` 抽样确认通常包含少数股东权益；权益 `<= 0` 为空。标准归母PB将在PIT财报层使用独立指标。 |
| `ps_ttm` | 滚动市销率、PS TTM | `总市值 / 营业收入TTM` | B | 收入 `<= 0` 为NM。 |
| `pcf_ttm` | 滚动市现率、P/CF | `总市值 / 经营现金流TTM` | A | 分母 `<= 0` 默认NM，同时保留原始CFO供解释。 |
| `ev_sales_ttm` | EV/Sales、企业价值营收倍数 | `企业价值 / 营业收入TTM` | C | 收入 `<= 0` 为NM。 |
| `ev_ebit_ttm` | EV/EBIT | `企业价值 / EBIT TTM` | C | EBIT `<= 0` 为NM。 |
| `ev_ebitda_ttm` | 企业倍数、EV/EBITDA | `企业价值 / EBITDA TTM` | C | EBITDA `<= 0` 为NM。 |
| `earnings_yield_ttm` | 盈利收益率（合并口径）、PE倒数 | `合并净利润TTM / 总市值` | A | 可保留负值；总市值 `<= 0` 为空。 |
| `fcfe_yield` | 股权自由现金流收益率 | `FCFE TTM / 总市值` | C | 可为负；与FCFF/EV收益率分开。 |
| `fcff_yield` | 企业自由现金流收益率 | `FCFF TTM / 企业价值` | C | EV `<= 0` 为空。 |
| `peg_forward` | PEG | `PE TTM / 未来盈利增长率百分数` | D | 约定增长率用“百分点数”，如20%以20代入；PE或增长率非正时为NM。 |
| `dividend_yield_ttm` | 股息率 | `过去12个月普通股现金股利 / 总市值` | D | 使用除权前后统一口径。 |

## 4. 盈利能力与杜邦指标

| 指标ID | 中文名 | 标准公式 | 等级 | 无效或特殊处理 |
|---|---|---|---|---|
| `gross_margin_ttm` | 毛利率TTM | `毛利润TTM / 营业收入TTM` | C | 金融企业不适用；收入 `<= 0` 为空。 |
| `operating_margin_ttm` | 营业利润率TTM | `EBIT TTM / 营业收入TTM` | C | 同一比较集必须使用相同EBIT定义。 |
| `ebitda_margin_ttm` | EBITDA利润率TTM | `EBITDA TTM / 营业收入TTM` | C | 收入 `<= 0` 为空。 |
| `net_margin_ttm` | 归母净利率TTM | `归母净利润TTM / 营业收入TTM` | B | 归母分子与合并收入存在口径差异，需在描述中明确。 |
| `roe_ttm` | 净资产收益率TTM、ROE | `归母净利润TTM / 平均归母股东权益` | B | 平均权益 `<= 0` 为NM。 |
| `roe_end_ttm` | 期末口径ROE | `归母净利润TTM / 期末归母股东权益` | A/B | 仅作为过渡/近似指标，不能与标准平均权益ROE混名。 |
| `roa_ttm` | 总资产收益率TTM、ROA | `净利润TTM / 平均总资产` | B | 分子使用合并净利润；平均资产 `<= 0` 为空。 |
| `roic_ttm` | 投入资本回报率TTM、ROIC | `NOPAT TTM / 平均投入资本` | C | 投入资本 `<= 0` 为NM；需固定税率和商誉处理。 |
| `asset_turnover_ttm` | 总资产周转率 | `营业收入TTM / 平均总资产` | B | 平均资产 `<= 0` 为空。 |
| `equity_multiplier` | 权益乘数 | `平均总资产 / 平均归母股东权益` | B | 权益 `<= 0` 为NM。 |
| `capital_turnover_ttm` | 投入资本周转率 | `营业收入TTM / 平均投入资本` | C | 投入资本 `<= 0` 为空。 |
| `dupont_roe_check` | 杜邦ROE校验 | `净利率 × 总资产周转率 × 权益乘数` | B | 只做一致性校验；分子若用归母净利润，权益也必须归母。 |

## 5. 偿债与资本结构指标

| 指标ID | 中文名/别名 | 标准公式 | 等级 | 无效或特殊处理 |
|---|---|---|---|---|
| `current_ratio` | 流动比率 | `流动资产 / 流动负债` | C | 流动负债 `<= 0` 为空。 |
| `quick_ratio` | 速动比率 | `(流动资产 - 存货) / 流动负债` | C | 第一版采用简化口径，后续可增加剔除预付款版本。 |
| `cash_ratio` | 现金比率 | `现金及现金等价物 / 流动负债` | C | 流动负债 `<= 0` 为空。 |
| `liabilities_to_assets` | 资产负债率、总负债率 | `总负债 / 总资产` | A | 总资产 `<= 0` 为空；适用于当前行情快照。 |
| `liabilities_to_equity` | 产权比率、总负债权益比 | `总负债 / 股东权益` | A/B | 不称为有息D/E；权益 `<= 0` 为NM。 |
| `debt_to_equity` | 有息债务权益比、D/E | `有息债务 / 股东权益` | C | 与产权比率严格分开。 |
| `debt_to_capital` | 有息债务资本比 | `有息债务 / (有息债务 + 股东权益)` | C | 分母 `<= 0` 为空。 |
| `net_debt_to_ebitda` | 净债务/EBITDA、净杠杆 | `净债务 / EBITDA TTM` | C | EBITDA `<= 0` 为NM；净现金企业可为负。 |
| `interest_coverage` | 利息保障倍数 | `EBIT TTM / 利息费用TTM` | C | 利息费用 `<= 0` 时标记“不适用”，不制造极大数。 |

## 6. 营运效率指标

| 指标ID | 中文名 | 标准公式 | 等级 | 无效或特殊处理 |
|---|---|---|---|---|
| `receivables_turnover` | 应收账款周转率 | `营业收入TTM / 平均应收账款` | C | 缺少赊销收入时标记为收入代理口径。 |
| `dso` | 应收账款周转天数 | `平均应收账款 / 营业收入TTM × 365` | C | 收入 `<= 0` 为空。 |
| `inventory_turnover` | 存货周转率 | `营业成本TTM / 平均存货` | C | 平均存货 `<= 0` 为空。 |
| `dio` | 存货周转天数 | `平均存货 / 营业成本TTM × 365` | C | 营业成本 `<= 0` 为空。 |
| `payables_turnover` | 应付账款周转率 | `营业成本TTM / 平均应付账款` | C | 缺采购额时标记为成本代理口径。 |
| `dpo` | 应付账款周转天数 | `平均应付账款 / 营业成本TTM × 365` | C | 营业成本 `<= 0` 为空。 |
| `cash_conversion_cycle` | 现金转换周期、CCC | `DSO + DIO - DPO` | C | 任一组成项缺失则为空；金融企业不适用。 |

## 7. 现金流质量与自由现金流

| 指标ID | 中文名 | 标准公式 | 等级 | 无效或特殊处理 |
|---|---|---|---|---|
| `cfo_to_net_profit` | 经营现金含量、盈利现金比 | `经营现金流TTM / 净利润TTM` | A/B | 净利润 `<= 0` 时默认不输出倍数，但保留两个基础量。 |
| `cfo_margin` | 经营现金流率 | `经营现金流TTM / 营业收入TTM` | B | 收入 `<= 0` 为空。 |
| `fcff_ttm` | 企业自由现金流 | `NOPAT + 折旧摊销 - CapEx - Δ非现金营运资本` | C | 负值有效；必须保留各组成项。 |
| `fcfe_ttm` | 股权自由现金流 | `净利润 + 折旧摊销 - CapEx - Δ营运资本 + 净新增有息债务` | C | 负值有效；不能与FCFF混用。 |
| `simple_fcf` | 简化自由现金流 | `经营现金流TTM - CapEx TTM` | C | 明确命名为简化FCF，不冒充严格FCFF/FCFE。 |

## 8. 增长与每股指标

| 指标ID | 中文名 | 标准公式 | 等级 | 无效或特殊处理 |
|---|---|---|---|---|
| `revenue_yoy` | 营收同比 | `本期累计收入 / 上年同期间累计收入 - 1` | B | 基期 `<= 0` 默认为空。 |
| `parent_net_profit_yoy` | 归母净利润同比 | `本期累计归母净利润 / 上年同期累计归母净利润 - 1` | B | 跨零时普通百分比会失真，返回空值并提供增减额。 |
| `revenue_qoq` | 单季度营收环比 | `本单季度收入 / 上一单季度收入 - 1` | B | 必须先还原单季度值。 |
| `profit_qoq` | 单季度归母净利润环比 | `本单季度归母净利润 / 上一单季度归母净利润 - 1` | B | 跨零时为空并提供增减额。 |
| `revenue_cagr_3y` | 三年营收复合增速 | `(末期收入 / 初期收入)^(1/3) - 1` | B | 两端必须为正且为同类年度值。 |
| `profit_cagr_3y` | 三年利润复合增速 | `(末期利润 / 初期利润)^(1/3) - 1` | B | 两端必须为正；跨零不计算。 |
| `sustainable_growth` | 可持续增长率 | `留存率 × ROE` | D | 需要现金分红；这是稳态估算而非预测。 |
| `book_value_per_share` | 每股净资产、BVPS | `归母股东权益 / 期末普通股股数` | D | 当前可由市值/股价反推股数，但不建议以反推值作为权威股本。 |
| `sales_per_share_ttm` | 每股营收 | `营业收入TTM / 加权平均普通股股数` | D | 股数口径需与期间匹配。 |
| `cfo_per_share_ttm` | 每股经营现金流 | `经营现金流TTM / 加权平均普通股股数` | D | 股数口径需与期间匹配。 |

## 9. 聚合、排序与展示规则

1. 公司层指标先按公司计算，再用于排行；行业整体倍数应使用“行业分子合计 / 行业分母合计”，不能简单平均公司倍数。
2. 需要“行业典型水平”时另外提供中位数，并排除NM值；中位数和整体聚合比率不能混称。
3. 百分比内部存储为小数，展示层再格式化；倍数统一标记为 `x`，天数为“天”。
4. 除增长率跨零等明确无意义情况外，经济上合理的负值应保留，例如负FCF、负净债务和负现金转换周期。
5. 所有指标结果建议同时保存 `as_of_date`、`source_report_date`、`source_publish_date`、`formula_version`、`quality_flag`。

## 10. 第一批建议上线范围

| 批次 | 指标 | 原因 |
|---|---|---|
| P0 | 合并口径PE TTM、总权益口径PB、PCF TTM、合并口径盈利收益率、资产负债率、产权比率 | 当前 `stock_daily` 已有直接依赖；名称明确披露与标准归母口径的差异。 |
| P1 | PS TTM、净利率、标准ROE、ROA、总资产周转率、经营现金含量、营收/利润同比 | 当前核心财报字段大体足够，重点是TTM与PIT处理。 |
| P2 | 毛利率、EBITDA、EV倍数、流动/速动比率、利息保障、周转天数、CCC、FCF、ROIC | 首批17个指标已上线；仅一般企业计算，金融企业返回空值。 |
| P3 | Forward PE、PEG、股息率、可持续增长率、每股扩展指标 | 需要预测、分红或可靠股本数据。 |
